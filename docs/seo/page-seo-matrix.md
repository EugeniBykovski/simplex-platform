# Page SEO matrix

Architecture and rationale: [seo-architecture.md](seo-architecture.md).

**The design defines no meta descriptions, Open Graph data or structured data.** Those columns are proposals. Titles marked below come from the design's document titles where it has a specific one. `ServicePage`, `IndustryPage`, `CasePage` and `LegalPage` carry generic titles such as "Service — SimpleX", so their titles are proposed from slug data. Descriptions are drawn from each page's own lead copy, unedited, so every one needs an editorial pass. 6 of 40 exceed 160 characters and need shortening.

H1s are the design's exact text, in English. Russian metadata ships with each page's translation.

## Rules applied to every row

- **Canonical:** the route itself on `NEXT_PUBLIC_SITE_URL`, with no query string. The production domain is not in the design (GAP-C08).
- **Open Graph:** title and description as above. No social image exists (GAP-A02).
- **hreflang:** only when a reviewed Russian version exists. None today.
- **Content uniqueness:** every service and industry page has its own headline, lead, capabilities and CTA in the design. Their section skeletons repeat, and the shared "first 30 days" block repeats verbatim.
- **Pagination:** `/insights` uses load more. All articles must also be crawlable as plain links, not only after a click.
